# Lux Aeterna — Dungeon Roguelike

Пошаговая roguelike RPG с процедурными подземельями, прокачкой персонажа и AI-персонажами — каждый моб, босс и NPC живёт своим характером и общается через LLM.

## Геймплей

- **Пошаговые бои** — атака, защита, исцеление, критические удары, побег, механика сдачи
- **Система подземелий** — процедурные карты по этажам или предзаданные уровни
- **Прокачка персонажа** — дерево навыков, характеристики, экипировка
- **AI-персонажи** — мобы, боссы и NPC общаются через LLM (Ollama / OpenRouter), каждый со своим характером и историей
- **Система боссов** — фазы с динамическим изменением поведения, encounter-тексты, спецатаки
- **AI-нарратор** — рассказчик перед боем, после поражения, при общении с NPC

> ⚠️ Этот проект разработан с активным использованием искусственного интеллекта. Все архитектурные решения, дизайн механик и концепция приняты автором.

## Быстрый старт

```bash
npm install
npm run start
```

Открыть `http://localhost:3000`. В настройках указать провайдер AI (Ollama (local) или OpenRouter).

## Стек

| Часть | Технология |
|-------|-----------|
| Backend | Node.js, Express |
| Frontend | Vanilla HTML / CSS / JS (без сборщиков) |
| AI | Ollama (локально) / OpenRouter (облако) |

## О движке

Игра построена на собственном data-driven движке — мобы, NPC, предметы, карты, боевая система и звуки управляются через JSON-манифесты без правки кода движка. В планах — вынести движок в отдельный репозиторий.

→ [Документация движка](docs/README.md)  
→ [Roadmap / идеи](roadmap/README.md) 

## Структура проекта

```
assets/
  config/           -- ядро движка (боевая система, звук, прогрессия, карты, навыки)
  mob/ boss/ npc/   -- манифесты существ
  item/             -- предметы и объекты
  player/ map/      -- спрайты персонажа и тайлы карт
  image/ skills/    -- UI-изображения и иконки навыков
  sound/            -- SFX и музыка (background / battle / ui)
  translation/      -- локализация (ru / en)
server/
  engine/           -- игровая логика (без HTTP)
  routes/           -- Express API
public/
  js/               -- ES-модули клиента
  index.html  style.css
save/               -- автосохранение и конфиг
docs/               -- документация движка
```
