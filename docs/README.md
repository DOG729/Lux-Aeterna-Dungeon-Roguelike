## Архитектура

```
┌────────────────────────────────────────────────────────────────┐
│  Браузер (public/)                                              │
│  ┌──────────────┐  ┌──────────────┐  ┌──────────────────────┐  │
│  │ index.html   │  │  style.css   │  │  public/js/  (ESM)   │  │
│  │ (разметка)   │  │  (стили)     │  │  main · combat ·     │  │
│  └──────────────┘  └──────────────┘  │  dungeon · skills ·  │  │
│                                      │  inventory · npc ·   │  │
│                                      │  sfx · music ·       │  │
│                                      │  dialogue · event ·  │  │
│                                      │  scavenge · …        │  │
│                                      └──────────────────────┘  │
│              ↕  fetch('/api/...')                               │
└────────────────────────────────────────────────────────────────┘
                       ↕ HTTP JSON
┌────────────────────────────────────────────────────────────────┐
│  Node.js + Express                                              │
│  ┌──────────────────────────────────────────────────────────┐  │
│  │  server/routes/  (Express routers)                        │  │
│  │    game · combat · inventory · npc · meta                 │  │
│  │    event · dialogue · scavenge                            │  │
│  └──────────────────────┬───────────────────────────────────┘  │
│                         ↓                                       │
│  ┌──────────────────────────────────────────────────────────┐  │
│  │  server/engine/  (чистая логика)                          │  │
│  │    data · combat · player · items · mob · boss ·          │  │
│  │    session · dungeon · ai · npc · dialogue · event_engine │  │
│  │    conditions · helpers · translation                     │  │
│  └──────────────────────────────────────────────────────────┘  │
│              ↕ aiChat()                                         │
│  ┌─────────────────────────┐  ┌───────────────────────────┐    │
│  │  Ollama / OpenRouter    │  │  assets/ + save/           │    │
│  │  (LLM, речь мобов/NPC)  │  │  (JSON-манифесты, спрайты) │    │
│  └─────────────────────────┘  └───────────────────────────┘    │
└────────────────────────────────────────────────────────────────┘
```

**Технологии:**
- Backend: Node.js, Express, fs (без БД — состояние в памяти + JSON-файлы)
- Frontend: Vanilla JS ES2022 (ES-модули), HTML5, CSS3
- AI: Ollama (локальный LLM) или OpenRouter (облачный), через REST
- Состояние игры: один объект `session` в памяти сервера + автосохранение в `save/.session.json`

## Стек запуска

```bash
npm install
npm start          # node server.js
npm run dev        # node --watch server.js
# → http://localhost:3000
```

Порт настраивается через `process.env.PORT`.

---

## Провайдеры AI

| Провайдер | Настройка |
|-----------|-----------|
| `ollama` | `url` + `model` (локальный сервер) |
| `openrouter` | `openrouterKey` + `openrouterModel` (облако) |

Переключение через `POST /api/settings` или интерфейс настроек.

## Настройки громкости

В `save/config.json` хранятся три ползунка:

| Ключ | Диапазон | По умолчанию | Описание |
|------|----------|--------------|----------|
| `bgVolume` | 0–1 | 0.25 | Громкость фоновой музыки |
| `battleVolume` | 0–1 | 0.25 | Громкость боевой музыки |
| `sfxVolume` | 0–1 | 0.2 | Громкость звуковых эффектов |

Подробнее о системе звука — в [sound.md](sound.md).
